# Sprite generation prompts

These sheets were generated with the built-in image generation tool, then converted from a flat magenta chroma-key background to alpha PNGs.

## Character pose sheet

```text
Use case: stylized-concept
Asset type: Phaser game character sprite pose sheet
Primary request: Create a clean 3 by 3 sprite pose sheet of the SAME child character for a Japanese voice-controlled watermelon-splitting beach game.
Subject: one cute 2.5-head-tall child wearing a blindfold and a bright coral-red Hawaiian aloha shirt with small cream tropical leaf patterns, navy shorts, barefoot, holding a light wooden suikawari stick with both hands. Soft rounded 3D anime game-render look, appealing and highly readable at small size.
Exact grid layout: 3 equal columns and 3 equal rows, with generous spacing and no overlap. Columns are camera views: column 1 front view facing the viewer, column 2 right-facing side profile, column 3 back view facing away from viewer. Rows are actions: row 1 neutral idle stance holding the stick safely, row 2 clear walking pose in that view, row 3 strong downward striking pose with the stick. Every cell contains exactly one full-body character, centered, same scale and identity. For the back-view poses the child's back and rear knot of the blindfold are clearly visible. For the side-view poses the character faces right.
Scene/backdrop: perfectly flat solid #ff00ff chroma-key background for background removal, including all gutters between cells.
Style/medium: polished soft 3D anime game sprite render, dimensional shading, cohesive with a bright illustrated tropical beach.
Composition/framing: orthographic-like game sprite views, full body including feet and entire stick, consistent ground line within each cell, generous padding.
Lighting/mood: warm sunny beach lighting on the character, cheerful.
Constraints: exact 3x3 grid; same character, clothing, proportions, blindfold and stick in all nine cells; no grid lines; no labels; no text; no numbers; no watermark; no cast shadow; no contact shadow; no reflection. The background must be one uniform #ff00ff with no gradient, texture, floor plane, or lighting variation. Do not use #ff00ff anywhere on the character. Crisp silhouette and clean separation from background.
Avoid: extra characters, cropped limbs, cropped stick, changing outfit, changing hair, changing colors, extra props, beach scenery, text, borders.
```

## Watermelon breaking sheet

```text
Use case: stylized-concept
Asset type: Phaser game watermelon animation sprite sheet
Primary request: Create a clean 2 by 4 sprite sheet showing normal and golden watermelons through a satisfying suikawari breaking animation.
Exact grid layout: 2 equal rows and 4 equal columns, generous spacing, no overlap. Top row is one normal green striped watermelon. Bottom row is the exact same watermelon made magical gold with warm yellow-gold rind and luminous orange-gold stripes. Columns show animation stages from left to right: column 1 whole intact round watermelon; column 2 first impact with a deep central crack and tiny rind chips; column 3 split into two large halves opening apart with red fruit visible for normal and rich golden-yellow fruit visible for gold; column 4 broken halves and several chunky rind pieces spread slightly outward, still compact and readable. Every cell contains exactly one centered animation stage at identical overall scale.
Scene/backdrop: perfectly flat solid #ff00ff chroma-key background for background removal, including all gutters.
Style/medium: polished soft 3D anime game sprite render, dimensional rounded shapes, juicy fruit, cohesive with a bright illustrated tropical beach and the matching child character sprite.
Composition/framing: three-quarter slightly elevated game view, clear silhouette, consistent ground line, generous padding around every stage.
Lighting/mood: warm sunny beach lighting, cheerful and playful.
Constraints: exact 2x4 grid; consistent watermelon design and scale across all stages; no text; no labels; no numbers; no grid lines; no watermark; no cast shadow; no contact shadow; no reflection; no splash droplets reaching other cells. Background must be one uniform #ff00ff with no gradient, texture, floor plane, or lighting variation. Do not use #ff00ff in the fruit. Crisp silhouette and clean separation from background.
Avoid: extra fruit, character, stick, beach scenery, photoreal gore, text, borders, cropped pieces.
```

## Crab walking sheet

```text
Use case: stylized-concept
Asset type: Phaser game crab walking sprite sheet
Primary request: Create a clean 2-column by 3-row sprite sheet of cute, highly deformed beach crabs for a Japanese watermelon-splitting game.
Subject: One adorable chibi crab design with a very wide rounded shell, tiny short legs, two oversized friendly claws, small raised eye stalks, and a cheerful simple face. The crab should feel like a charming background animal, not a main character. Row 1 is coral red, row 2 is turquoise blue, row 3 is warm orange. In every row, column 1 and column 2 show two distinct sideways walking poses of the exact same crab, with alternating legs and slight claw bounce. Every cell contains exactly one full crab, front-facing body while clearly scuttling sideways, centered at the same size and on the same ground line.
Scene/backdrop: perfectly flat solid #ff00ff chroma-key background for background removal, including all gutters between cells. The background must be one uniform color with no shadows, gradients, texture, reflections, floor plane, or lighting variation.
Style/medium: polished soft rounded 3D anime game sprite render, dimensional but simple forms, cohesive with a bright illustrated tropical beach and a cute 2.5-head-tall child character in a coral Hawaiian shirt.
Composition/framing: exact 2 equal columns and 3 equal rows, generous uniform padding, no overlap, orthographic-like game sprites, clear compact silhouettes.
Lighting/mood: warm sunny beach lighting on each crab, cheerful and playful.
Constraints: exact 2x3 grid; same crab proportions and identity in all six cells; only shell color changes per row; each crab fully visible; no grid lines; no labels; no text; no numbers; no watermark; no cast shadow; no contact shadow; no reflection. Do not use #ff00ff anywhere on the crabs. Crisp edges and clean separation from background.
Avoid: realistic anatomy, scary pincers, extra animals, extra props, beach scenery, water, sand, cropped legs or claws, merged cells, borders, text.
```
