# ヒューマンタワーバトル 2026 操作マニュアル

対象: macOS / Human Tower Battle 2026 完全版

## 1. 起動前の確認

- カメラの前に全身が映るスペースを確保します。
- 「システム設定 > プライバシーとセキュリティ > カメラ」で、使用するターミナルを許可します。
- 設定を変更した場合は、ターミナルを一度終了して開き直します。
- ゲームのフォルダは次の場所です。

```text
human_tower_battle_2026
```

## 2. カメラ番号を確認する

ターミナルで次を実行します。

```bash
cd human_tower_battle_2026
~/.venvs/human_tower_battle_2026/bin/python games/camera_check.py
open camera_check_output/contact_sheet.jpg
```

比較画像に表示された `Camera 0`、`Camera 1` などの番号から、使用するカメラ番号を選びます。

## 3. 完全版を起動する

カメラ0を使う例です。番号は確認結果に合わせて変更してください。

```bash
cd human_tower_battle_2026
HTB_CAMERA_INDEX=0 ~/.venvs/human_tower_battle_2026/bin/python games/main.py
```

SAM2 largeモデルをCPUで読み込むため、画面が開くまで30秒前後かかる場合があります。

## 4. ゲームの基本操作

1. スタート画面の「ゲーム開始」をマウスでクリックします。
2. 頭から足までがプレビュー内に入るようにします。左右や画面下側にいても撮影できます。
3. 切り抜きたい人物の胴体をプレビュー上で1回クリックします。黄色い照準が表示されれば選択完了です。
4. 複数人が近くにいる場合は、対象の頭から足までをドラッグして黄色い枠で囲みます。
5. 右上が緑色の「クリック指定済み」または「範囲指定済み」になったら、`Enter` キーを押します。画面左側の撮影パネルをクリックしても撮影できます。
6. 切り抜かれた人物が待機中に `1`、`2`、`3` のいずれかを押して落とします。
7. 人物が落下したら、次の人物を指定して撮影します。
8. タワーをできるだけ高く積み上げます。

人物の指定を変えるときは再クリックまたは再ドラッグします。指定を消すときは、カメラプレビュー上で右クリックします。人物を指定せずに撮影した場合は、従来どおり自動検出が使われます。

### キーとボタン

| 操作 | 動作 |
|---|---|
| カメラ画面をクリック | クリックした人物を切り抜き対象にする |
| カメラ画面をドラッグ | 黄色い枠で囲んだ人物を切り抜き対象にする |
| カメラ画面を右クリック | 人物の指定を解除する |
| `Enter` / 撮影パネルのクリック | 人物を撮影し、次のピースを作る |
| `1` | 台の左側へ配置して落とす |
| `2` | 台の中央へ配置して落とす |
| `3` | 台の右側へ配置して落とす |
| `D` | まだ落としていない人物を破棄する |
| マウス | 「ゲーム開始」「もう一度プレイ」「終了」を選ぶ |

待機中の人物を落とすか `D` で破棄するまでは、次の撮影はできません。

## 5. ゲームオーバー

積み上げた人物が画面下部の床まで落ちるとゲームオーバーです。結果画面には積み上げ人数と当日のランキングが表示されます。

- 「もう一度プレイ」: スコアをリセットして再開します。
- 「終了」: ゲームを閉じます。

## 6. 表示・起動オプション

### カメラやSAM2を使わないデモモード

```bash
HTB_DEMO_MODE=1 ~/.venvs/human_tower_battle_2026/bin/python games/main.py
```

### 左側の外部縦モニターへ表示

```bash
HTB_USE_EXTERNAL_MONITOR=1 ~/.venvs/human_tower_battle_2026/bin/python games/main.py
```

### ウィンドウサイズを指定

```bash
HTB_WINDOW_WIDTH=720 HTB_WINDOW_HEIGHT=1245 ~/.venvs/human_tower_battle_2026/bin/python games/main.py
```

### 表示倍率を指定

```bash
HTB_WINDOW_SCALE=0.9 ~/.venvs/human_tower_battle_2026/bin/python games/main.py
```

## 7. 困ったとき

### カメラが開かない

1. 「システム設定 > プライバシーとセキュリティ > カメラ」でターミナルを許可します。
2. ターミナルを終了して開き直します。
3. `camera_check.py` を再実行し、正しいカメラ番号を確認します。

### 「人物を切り抜けません」と表示される

- 人物の頭から足までが画面内に入るよう、カメラから少し離れます。
- まず人物の胴体をクリックします。複数人が映る場合は、対象の全身だけをドラッグで囲みます。
- 別の人物が選ばれる場合は、対象を少し狭めに囲み直してから `Enter` を押します。
- 明るい場所で、背景と服の色がはっきり分かれる位置に立ちます。
- 左右や画面下側でも認識できますが、人物全体が画面内へ収まるようにします。
- プレビューが緑色の「人物を検出」になるまでカメラの高さ・角度を調整します。
- テレビや棚などの大きな物体を人物として誤認しないよう、人物の周囲に余白を作ります。

原因を詳しく確認する場合は、診断保存を有効にして起動します。

```bash
HTB_SAVE_SEGMENT_DEBUG=1 HTB_CAMERA_INDEX=0 ~/.venvs/human_tower_battle_2026/bin/python games/main.py
open segmentation_debug
```

撮影時の人物検出枠とマスクが `segmentation_debug/` に保存されます。

### 起動に時間がかかる

SAM2 largeモデルをCPUに読み込むためです。起動直後は30秒程度待ちます。

### `objc` や `SDL` の警告が表示される

PygameとOpenCVがそれぞれSDLを同梱しているために表示される警告です。ゲーム画面が開けば、そのまま利用できます。

## ローカル保存場所

- 仮想環境: `~/.venvs/human_tower_battle_2026`
- SAM2モデル: `sam2/checkpoints/sam2.1_hiera_large.pt`
- ランキング: `games/ranking.json`
- セグメンテーション診断画像: `segmentation_debug/`（診断を有効にした場合のみ）
